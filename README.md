# OIBSIP_DataAnalytics_Level1_Project1
Exploratory Data Analysis on Retail Sales Data using Python.

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to uncover sales trends, customer purchasing behavior, and product performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Retail Sales Dataset (sourced from Kaggle)
Contains transaction-level data including date, product category, customer details, quantity, and total sales amount

## Analysis Performed
- Data Cleaning
- Descriptive Statistics
- Monthly Sales Analysis
- Product Category Analysis
- Gender Analysis
- Age Analysis
- Correlation Analysis

## Conclusion
The analysis revealed variations in monthly sales performance, identified the highest-performing product category, and highlighted the impact of pricing and purchase quantity on revenue generation. These insights can support better inventory planning, marketing strategies, and business decision-making.
